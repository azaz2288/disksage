# Windows运行与数据恢复

README提供浏览器和Tk目录选择入口。便携包为未签名测试构建，整个dist/DiskSage目录一起使用；原生窗口用于选择目录，实际分析工作台在浏览器。程序无需管理员权限。

扫描报告仅用户手动导出，路径敏感，不提交Git。完整扫描快照保存在data/scans/*.db，可在“历史扫描”恢复；无权访问的项目另存原因。扫描自动排除程序数据目录，避免把正在增长的扫描数据库计算进结果。备份data/app.db与实际隔离目录，不能只恢复数据库。隔离目录固定在允许临时根目录内 .disksage-quarantine。

pending表示移动意图、restoring表示恢复link/unlink中断、purging表示独立确认的删除意图；历史页面处理可判断状态，恢复中断可重试。批次恢复按项返回冲突，不覆盖同名文件。永久删除只支持隔离记录的精确确认，禁止定时任务自动执行。

桌面构建需PyInstaller，签名需要有效证书；当前不冒称已经签名或正式安装器。

# DiskSage · 磁盘分析与安全整理

**v0.3.3 可运行功能版**。默认只允许本机访问。

## 已实现

- 只读后台扫描、取消、权限错误与部分结果；驱动器容量选择、原生目录选择启动器
- 逻辑大小、硬链接去重大小、系统分配空间；目录下钻、面积图、扩展名分布、大文件排行、JSON报告
- 按大小筛选与SHA256复核重复内容；读取预算与变化校验，仅生成审查清单
- 七天以上 .tmp/.log 临时候选，隔离预览、2GiB配额、批次撤销、重启恢复日志
- 隔离记录可独立输入“永久删除”确认释放空间；恢复遇到同名不覆盖，恢复中断可重试
- 页面配置兼容API地址、模型和Key；默认只发送类型/大小汇总，可勾选允许路径并预览确认，用实际大文件与目录记录提问；模型不能触发文件操作

## 历史扫描对比（v0.3）

侧栏“历史扫描对比”选择同一根目录的两份历史清单，查看新增观察、未再观察到与逻辑大小变化；显示变化项数量与有符号净字节差，支持目录范围、路径文字和变化类型筛选，每页100项，CSV导出全部筛选结果而非当前页。新页面按完成时间选择基线/当前，不依赖重启后文件枚举顺序。

比较仅通过只读SQLite连接读取已保存明细，不重扫、不读取源文件正文/元数据、不执行隔离或删除，不调用AI。两次扫描取消或存在访问失败时，页面和CSV明确保留覆盖不完整状态；“未再观察到”不是已删除证明。相同大小的内容变化不检测，重命名表现为一个未再观察到与一个新增。路径按清单保存的字符串匹配，不提供跨根范围比较、跨平台迁移或跨文件原子快照。

API：`GET /api/comparisons?baseline=扫描ID&current=扫描ID` 返回分页变化、筛选范围内counts/delta_bytes/coverage/warnings；可选`path`、`q`（文字，不是通配符）、`kind=all|added|removed|resized`、`offset`、`limit`（1–500）。`GET /api/comparisons.csv`使用同样筛选，忽略分页。未知ID返回404，未完成扫描409，根目录不一致/越界400，未扫描目录404，参数无效422。导出在发送CSV响应头前验证范围，并保护路径公式开头；导出包含本机路径，需要自行保护，不上传第三方。

合成演示：`.venv/Scripts/python.exe tools/comparison_demo.py --port 8892`，只创建临时项目和应用数据，退出自动移除，不加载现有用户磁盘清单。基准：`.venv/Scripts/python.exe tools/comparison_benchmark.py --rows 50000`，两份5万条合成SQLite清单全部大小变化，含聚合的尾页耗时0.281546秒，单独Python内存峰值47786B；不是文件扫描吞吐、原生RSS、优化倍率或生产SLA。SQL仍需遍历清单及排序，百万记录diff未实测，增量扫描仍未完成。

## 显式子目录刷新（v0.3.1）

恢复一份可访问范围完整的全量历史扫描，在“目录探索”进入其中一个已登记子目录，点击“刷新当前子目录…”并确认范围。仅重新遍历选中子树，其余文件沿用基线旧记录；新清单重新聚合目录、扩展名和硬链接统计，并明确标注“混合时间清单/外部目录未复验”。原基线保持不变。刷新结果不生成清理候选，不能串联下一次局部刷新；需要全根当前统计请完整扫描。

API：`POST /api/scans/{baseline}/refresh`，JSON `{"path":"绝对子目录路径"}`，返回新后台任务ID。根目录、未登记/越界/链接目录、不完整或局部刷新基线拒绝；运行中的任务返回409。扫描取消、访问失败、写入或同步失败不发布新清单；独占发布不覆盖已存在输出。应用重启后可恢复已完成清单和混合时间说明。

v0.3.2 页面可指定总预算；JSON可选 `"timeout_seconds":300`，严格整数1–3600，省略默认300，非法值422。任务开始后的选中扫描、外部复制、SQLite聚合和发布前同步共用monotonic期限；预检/排队不计。SQLite每1000 VM操作检查，Python在阶段/循环边界检查；超时`timed_out`、主动取消`cancelled`均不发布新清单，页面恢复原基线供显式重新预览重试，不自动重试。成功metadata保存预算与`elapsed_before_sync_seconds`（聚合结束、同步前的累计秒数，不是整个任务耗时）。失败/取消状态仅内存，重启后仍能恢复原基线。

这不是硬实时、CPU/RSS/磁盘限额或原子文件系统截止保证：阻塞IO、Python内建排序、暂存回收可能越过预算，独占发布前检查与硬链接调用间仍有极小竞态。合成预算演示 `.venv/Scripts/python.exe tools/budget_demo.py --port 8900` 使用独立临时7B基线及人工2秒延迟（不是性能测量）；1秒超时、取消和9秒手动成功可核验，按Enter停止。维护不扫描真实用户磁盘、不执行清理。

合成演示：`.venv/Scripts/python.exe tools/refresh_demo.py --port 8896`，退出移除独立临时数据。不读取现有用户清单。此功能不是自动变更检测、崩溃续扫或跨文件原子快照；未刷新部分（包括硬链接身份/大小/分配量）是历史观察，不能当作当前磁盘真值。不支持硬链接发布的文件系统失败关闭；进程崩溃可能留下 `.refresh-*` 临时清单，尚无自动恢复/目录fsync。旧便携下载未重建，不含此新功能。

### 选中子树的文件变化摘要（v0.3.3）

显式刷新成功后，页面及JSON `result.refresh.changes`记录选中子树相对基线的文件观察：`added`新增、`removed`未再观察、`replaced`身份替换、`resized`大小变化、`metadata_changed`其余元数据变化、`unchanged`元数据未变。按此优先级互斥，一次替换同时改变大小/时间只计替换；before/after_files、before/after_bytes与delta_bytes给出范围内前后值/净差。整根总量仍是混合时间记录；外部旧行不参与这份摘要，不读取其源路径。

这是文件元数据检测，不读取正文、不证明内容一致：mtime纳秒变化可识别同大小普通修改，但保留身份/大小/mtime的内容修改会漏检。身份基于非零inode与device，零inode不判替换，inode复用和文件系统差异也会限制可靠性。重命名表现为未再观察+新增，未再观察不证明真实删除；目录增删不计入文件六类。自动监控和崩溃续扫仍未实现。旧清单缺少该字段时页面显示“未记录”，不伪造为零。旧历史比较页面仍只检测大小变化。

合成六类演示：`.venv/Scripts/python.exe tools/changes_demo.py --port 8902`，浏览器恢复baseline、进入selected、确认只读刷新，可见六类各1，选中21B→32B/+11B，外部1文件仍沿用4B。只创建独立临时目录和库存，按Enter停止并清理自己的演示数据；不是实际磁盘性能测量，不触及真实清单或旧服务。

## 启动

Python 3.12，Windows PowerShell：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

打开 http://127.0.0.1:8765 。已有依赖时可用 `run.cmd`。其他系统使用 `.venv/bin/python`。`APP_DATA_DIR`覆盖数据目录。

## 可选AI

页面“API设置”填写兼容地址、模型与Key，Key仅在服务端内存保存，重启后使用环境变量。也可设置 `LLM_API_KEY`、`LLM_MODEL`、`LLM_BASE_URL`；不自动读取.env。不要提交或截图密钥。AI操作需用户主动触发，按服务商计费。本轮没有使用付费API。

原生目录选择：`python -m app.desktop`。Windows便携包构建：`powershell -File tools/build-desktop.ps1`；输出dist/DiskSage，整个目录一起分发。打包版数据默认写入LOCALAPPDATA/disksage/data，不会写程序资源目录。

## 已知边界

- 目录扫描不是原子快照；无权访问和动态变化会影响统计，页面显示覆盖状态并可查看失败项目。系统分配数不包含文件系统元数据。
- 扫描默认没有文件/目录数量截断，明细写入本机SQLite；每页100项并可继续翻页、全局搜索、排序、CSV导出和重启恢复。可选扫描限额与取消仍支持；重复检查每文件1GiB、读预算10GiB。
- 隔离仍占空间；只有用户独立确认永久删除才释放。不能自动清理用户文档或重复文件。
- 路径校验不是对抗有本机文件写权限攻击者的操作系统沙箱。
- Windows便携包已构建和启动验证，未签名；正式安装器和签名证书尚未提供。
